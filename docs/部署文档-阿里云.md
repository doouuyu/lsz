# 李时珍智能医师 —— 部署 & 运维文档

生产域名：**`https://taoism.test.doouu.cc`**（已备案 + HTTPS 证书）
后端 `/api`、报告 `/reports`、PC 管理端静态站都挂在这一个域名下（同域），无跨域、小程序也满足 https 要求。

> 本文档分三部分：**第一部分**讲架构和服务器现状（先读懂）；**第二部分**是日常维护（最常用）；**第三部分**是全新服务器从零部署（换机/重装时用）。

---

# 第一部分 · 架构与现状

## 1.1 三端总览

| 模块 | 部署目标 | 方式 |
|------|----------|------|
| `backend/` FastAPI | 阿里云 ECS | Python venv + gunicorn(**单 worker**) + systemd，nginx 反代到 `127.0.0.1:8000` |
| `frontend/` PC 管理端 | 同一台 ECS | 本地 `npm run build` → 上传 `dist/` → nginx 静态托管 |
| `mobile/` 小程序 | 微信平台 | 微信开发者工具上传审核；**不放服务器**，只需配「合法域名」 |

## 1.2 请求流向

```
浏览器/小程序 ──https──> nginx(443) ┬─ 路径 /          → 返回 /var/www/taoism/frontend 里的网页(PC端)
                                    ├─ 路径 /api/...   → 转发给 127.0.0.1:8000 后端
                                    ├─ 路径 /reports/  → 转发给 127.0.0.1:8000（PDF 报告）
                                    └─ 路径 /health    → 转发给 127.0.0.1:8000（健康检查）
       http(80) ─────────────────> nginx → 301 跳转到 https
```

后端只监听 `127.0.0.1:8000`，外网进不来（安全）；一切对外流量都经 nginx。

## 1.3 服务器上各文件的位置（关键路径速查）

| 用途 | 路径 |
|------|------|
| 后端代码 | `/root/taoism/backend/` |
| 后端虚拟环境 | `/root/taoism/backend/.venv/` |
| 后端环境变量（含密钥） | `/root/taoism/backend/.env` |
| 知识库数据（chroma 等） | `/root/taoism/backend/data/` |
| embedding 模型缓存 | `/root/taoism/hf_cache/` |
| 部署配置暂存区 | `/root/taoism/deploy/` |
| **PC 前端静态文件** | `/var/www/taoism/frontend/`（**不能放 /root，见 4.6**） |
| systemd 服务定义 | `/etc/systemd/system/lsz-backend.service` |
| nginx 站点配置 | `/etc/nginx/conf.d/lsz.conf` |
| SSL 证书 | `/etc/nginx/ssl/taoism.test.doouu.cc.{pem,key}` |

## 1.4 关键约束（改动时务必遵守）

| 约束 | 原因 |
|------|------|
| 后端 **`--workers 1`** | 会话/舌诊任务/化验单结果存进程内内存（`services/session.py` 等），多 worker 会丢状态。要扩容须先改 Redis |
| 后端 `.env`：`HOST=127.0.0.1`、`DEBUG=false` | 外网由 nginx 反代；关掉热重载 |
| 前端必须放 `/var/www`，不能放 `/root` | nginx worker 以 `www-data` 运行，无权进 `/root`(700)，否则 500 |

### V2 多模态问诊补充

- 在 `backend/.env` 配置同一华北 2（北京）Workspace 的
  `BAILIAN_API_KEY`、`BAILIAN_WORKSPACE_ID`、专属 HTTP/WSS 地址；
- 固定模型必须保持 `qwen3.7-plus-2026-05-26` 和
  `fun-asr-realtime-2026-02-28`，不得配置浮动别名或备用模型；
- 执行 `python scripts/build_asr_hotwords.py --sync`，将输出的
  `vocabulary_id` 写入 `ASR_VOCABULARY_ID`；
- 微信公众平台除 request/uploadFile 域名外，还需配置 Socket 合法域名；
- Nginx 必须保留 `/api/v2/asr/realtime` 的 Upgrade/Connection 头；
- V2 会话和任务在进程内，必须继续使用单 worker。回滚时可恢复上一版应用代码和
  Nginx 配置；旧 `/api/chat/*`、`/api/tongue/*`、`/api/lab/*` 不受 V2 影响。

故障排查：

- `MODEL_UNAVAILABLE`：检查 Key、Workspace、地域、模型开通与余额；
- `ASR_UNAVAILABLE`：检查 WSS 专属域名、Socket 合法域名和热词 ID 是否与模型同账号；
- `CONSULTATION_EXPIRED`：会话已超过 30 分钟，需重新开始；
- 上传被拒：核对扩展名、MIME、真实文件签名、10MB/30MB 限制和 PDF 8 页限制；
- 服务重启后旧任务丢失是 P0 预期行为，客户端应提示重新开始。
| 无需装 Redis / PostgreSQL | 配置项虽在但运行时未使用（全内存态） |
| embedding 走 `HF_ENDPOINT=https://hf-mirror.com` | 国内直连 HuggingFace 极慢 |

# 第二部分 · 日常维护

> 绝大多数情况只用到这一部分。本地改完代码，跑一条命令同步即可。

## 2.1 更新后端代码

```bash
# 本地项目根目录执行：同步代码+数据，并自动重启服务
bash deploy/deploy.sh backend && ssh root@taoism.test.doouu.cc 'systemctl restart lsz-backend'
```

## 2.2 更新 PC 前端页面

```bash
# 自动 build + 上传到 /var/www/taoism/frontend + chown，无需重启 nginx（静态文件即时生效）
bash deploy/deploy.sh frontend
```
浏览器强刷（Cmd+Shift+R）即可看到新版本。

## 2.3 更新知识库

知识库重新生成后（本地跑 `scripts/generate_kb.py` / `build_vector_index.py`，产物在 `backend/data/`）：

```bash
bash deploy/deploy.sh backend && ssh root@taoism.test.doouu.cc 'systemctl restart lsz-backend'
# 重启后验证条数
curl https://taoism.test.doouu.cc/health
```

## 2.4 更新小程序

代码侧无需改（发布自动用线上域名）。改完后：微信开发者工具打开 `mobile/` → `npm run build:mp-weixin` → 真机预览 → 「上传」提交审核。

## 2.5 修改 API 密钥 / 模型

```bash
ssh root@taoism.test.doouu.cc
vim /root/taoism/backend/.env        # 改 DEEPSEEK_API_KEY / VL_API_KEY / 模型名等
systemctl restart lsz-backend        # .env 改动必须重启才生效
```

## 2.6 看日志 / 查状态 / 重启

```bash
# 后端
systemctl status lsz-backend             # 运行状态
journalctl -u lsz-backend -f             # 实时日志（排错首选）
systemctl restart lsz-backend            # 重启
systemctl stop  lsz-backend              # 停止

# nginx
nginx -t                                 # 改完配置先测语法
systemctl reload nginx                   # 平滑重载（不断连接）
tail -f /var/log/nginx/error.log         # 网关错误日志
```

## 2.7 SSL 证书续期（重要，别忘）

阿里云免费证书有效期约 1 年，到期前去控制台重新签发，下载 **Nginx 版**，替换同名文件后重载：

```bash
# 本地把新证书覆盖上去（文件名保持不变）
scp ~/Downloads/taoism.test.doouu.cc.pem root@taoism.test.doouu.cc:/etc/nginx/ssl/
scp ~/Downloads/taoism.test.doouu.cc.key root@taoism.test.doouu.cc:/etc/nginx/ssl/
# 服务器重载
ssh root@taoism.test.doouu.cc 'nginx -t && systemctl reload nginx'
```

## 2.8 备份（建议定期，尤其换机前）

需要备份的只有这几样（代码在本地仓库，不用备）：

```bash
# 在服务器打包，下载到本地保存
tar czf ~/taoism-backup.tgz \
    /root/taoism/backend/.env \
    /root/taoism/backend/data \
    /etc/nginx/conf.d/lsz.conf \
    /etc/nginx/ssl \
    /etc/systemd/system/lsz-backend.service
```

# 第三部分 · 全新服务器从零部署

> 换服务器、重装系统时按此顺序走一遍。预计 30–60 分钟（pip 装 torch 较久）。

## 准备工作（开始前确认）

- [ ] 一台 ECS（建议 Ubuntu 22.04 / ≥4G 内存，单 worker 约占 1.5–2G）
- [ ] 域名已解析到新服务器公网 IP
- [ ] 阿里云安全组放行 **80、443**（8000 不对外）
- [ ] 手上有该域名的 SSL 证书（Nginx 版 pem/key）
- [ ] 本地能 SSH 登录新服务器，且 `deploy/deploy.sh` 顶部 `SERVER` 已指向它

## 步骤 1：装系统依赖、建目录（服务器）

```bash
sudo apt update
sudo apt install -y python3.11 python3.11-venv python3-pip nginx rsync \
    libpango-1.0-0 libpangocairo-1.0-0 libgdk-pixbuf-2.0-0 libffi-dev libcairo2 \
    libjpeg-dev zlib1g-dev        # 后三个是 WeasyPrint 生成 PDF 所需系统库

sudo mkdir -p /root/taoism/{backend,hf_cache,deploy}
sudo mkdir -p /var/www/taoism/frontend
```

## 步骤 2：上传后端代码+数据、部署配置（本地 Mac）

```bash
bash deploy/deploy.sh backend     # 同步 backend/ 和 data/ 到 /root/taoism/backend
# 把 systemd 和 nginx 配置传到暂存区（deploy.sh 不含 deploy/ 目录本身）
scp deploy/lsz-backend.service deploy/nginx-lsz.conf \
    root@taoism.test.doouu.cc:/root/taoism/deploy/
```

## 步骤 3：装 Python 依赖、配 .env（服务器）

```bash
ssh root@taoism.test.doouu.cc
cd /root/taoism/backend
python3.11 -m venv .venv && source .venv/bin/activate
pip install -U pip
export HF_ENDPOINT=https://hf-mirror.com
pip install -i https://mirrors.aliyun.com/pypi/simple/ -r requirements.txt
pip install gunicorn

# 创建 backend/.env（后端只认这个文件名；当前目录就是 /root/taoism/backend）
cat > .env <<'EOF'
HOST=127.0.0.1
PORT=8000
DEBUG=false
LLM_PROVIDER=deepseek
DEEPSEEK_MODEL=deepseek-v4-flash
DEEPSEEK_API_KEY=填你的真实key
VL_API_KEY=填你的真实key
EOF
vim .env        # 确认/填入真实 key
```

## 步骤 4：冒烟测试 + 注册 systemd 服务（服务器）

```bash
# 测试知识库能否加载（首次会下载 embedding 模型到 hf_cache，稍慢）
HF_ENDPOINT=https://hf-mirror.com .venv/bin/python -c \
  "from app.services.knowledge import knowledge_service; knowledge_service.load(); print(knowledge_service.stats())"

# 注册为开机自启、崩溃自重启的常驻服务
sudo cp /root/taoism/deploy/lsz-backend.service /etc/systemd/system/
sudo systemctl daemon-reload          # 改过 .service 文件后都要执行
sudo systemctl enable --now lsz-backend
sudo systemctl status lsz-backend     # 看到 active (running) 即成功
curl http://127.0.0.1:8000/health     # 返回 status ok + 知识库条数
```

## 步骤 5：上传前端 + SSL 证书（本地 Mac）

```bash
bash deploy/deploy.sh frontend        # build + 同步到 /var/www/taoism/frontend + chown www-data
# 上传证书（文件名必须与 nginx 配置里一致）
ssh root@taoism.test.doouu.cc 'mkdir -p /etc/nginx/ssl'
scp ~/Downloads/taoism.test.doouu.cc.pem root@taoism.test.doouu.cc:/etc/nginx/ssl/
scp ~/Downloads/taoism.test.doouu.cc.key root@taoism.test.doouu.cc:/etc/nginx/ssl/
```

## 步骤 6：配置并启动 nginx（服务器）

```bash
sudo cp /root/taoism/deploy/nginx-lsz.conf /etc/nginx/conf.d/lsz.conf
sudo nginx -t                         # 必须看到 successful
sudo systemctl enable --now nginx     # 已在跑则用 reload
```

## 步骤 7：验证

```bash
curl -I http://taoism.test.doouu.cc            # 期望 301 → https
curl https://taoism.test.doouu.cc/health       # 期望 {"status":"ok", ...}
```
浏览器开 `https://taoism.test.doouu.cc`：有锁图标、出 PC 管理端、F12 看 `/api` 请求 200。

## 步骤 8：小程序合法域名（微信公众平台）

**开发管理 → 开发设置 → 服务器域名**，把 `https://taoism.test.doouu.cc` 加入：
- **request 合法域名**
- **uploadFile 合法域名**（舌诊、化验单上传必配）
- **downloadFile 合法域名**（报告 PDF 预览/下载）

## 上线最终勾选

- [ ] DNS、安全组(80/443)、SSL 证书就位
- [ ] `backend/.env`：真实 key、`HOST=127.0.0.1`、`DEBUG=false`
- [ ] `/health` 返回知识库条数 > 0
- [ ] systemd 服务 `--workers 1`、开机自启、running
- [ ] PC 端能打开且 `/api` 调通
- [ ] 微信三类合法域名已配
- [ ] 小程序真机：聊天、舌诊上传、化验单上传、报告查看全走通

# 附录 · 故障速查

| 现象 | 原因 / 处理 |
|------|-------------|
| nginx 启动失败 `bind() to 0.0.0.0:80 failed` | 80 端口被别的进程占用。`sudo ss -ltnp \| grep ':80 '` 找出并停掉，或让对方改端口 |
| `nginx -t` 报 `cannot load certificate` | 证书路径/文件名不对或没上传，核对 `/etc/nginx/ssl/` |
| 浏览器证书警告 | 不是该域名证书，或 `.pem` 不完整（要用阿里云 **Nginx 版**，含证书链） |
| 访问到 nginx 默认欢迎页 | 删 `sites-enabled/default` 后 reload |
| 网页能开但 `/api` 502 | 后端没跑。`systemctl status lsz-backend` + `journalctl -u lsz-backend -f` |
| 网页 500，日志 `stat() ... Permission denied` | 前端放在了 `/root` 下。挪到 `/var/www/taoism/frontend` 并 `chown www-data`（deploy.sh 已自动处理） |
| 网页 404/空白 | `/var/www/taoism/frontend/` 没有 index.html，重跑 `deploy.sh frontend` |
| 域名连接超时 | 安全组没放行 443/80，或 DNS 没解析到本机 |
| 小程序上传图片失败 | uploadFile 合法域名没配 |
| 后端起不来、卡在加载 | 多半 embedding 模型下载失败，确认 `HF_ENDPOINT` 镜像生效，或检查 `data/chroma` 是否同步上来 |

> 可选安全收紧：`backend/app/main.py` 的 CORS 现为 `allow_origins=["*"]`。PC 端同域、小程序不走 CORS，不影响功能；上线稳定后可改为只允许 `https://taoism.test.doouu.cc`。
