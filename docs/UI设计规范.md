# 《李时珍智能医师》UI 设计规范 v1.0

> 视觉方向经 ui-ux-pro-max 设计引擎分析 + 与产品方确认（2026-06-07）。
> 本文档是前端视觉的唯一事实来源（Source of Truth），所有页面实现以此为准。

---

## 一、设计哲学：A+B 混合「双表面系统」

项目视觉需同时满足三个相互拉扯的目标：

1. **惊艳** —— 面向院士/专家的学术汇报，需要第一眼记忆点（"汇报杀手锏"）。
2. **懂行 / 庄重** —— 中医专家最反感"花哨"，配色字体须有文化底蕴。
3. **适老 / 高可读** —— 基层医生与老年用户，要求大字号、高对比、低认知负荷。

解法是**双表面**：整站默认「古籍宣纸面」，仅在数据可视化区域切换到「藏青深色面」。
古籍面负责文化与可读性，深色面负责科技感与图表表现力，两者用同一套字体与强调色（朱砂 / 金）统一。

### 表面映射规则

| 表面 | 应用范围 | 职责 |
|---|---|---|
| 🟫 **古籍面**（宣纸暖底） | 首页主体、四时养生、五脏调养、慢病助手、知识检索列表、溯源弹窗、PDF 报告 | 懂行 · 文化 · 适老 |
| 🟦 **藏青面**（深色沉浸） | 仿真辨证「结果可视化区」、知识图谱「力导向画布」、首页「架构流程条」 | 科技 · 惊艳 · 让 ECharts 发光 |

> 全站**不做**明暗模式切换：双表面本身已提供明暗对比，全局暗色会让古籍质感失真。

## 二、颜色系统（CSS Token）

```css
:root {
  /* —— 古籍面 —— */
  --paper:        #F3ECDD;  /* 宣纸底 */
  --paper-card:   #FBF7EE;  /* 卡片（略亮暖白） */
  --paper-sunken: #ECE2CE;  /* 凹陷区 / 次级底 */
  --ink:          #1F1B16;  /* 主文字（墨） */
  --ink-2:        #5C5345;  /* 次文字 */
  --ink-3:        #8A7E6A;  /* 辅助 / 占位 */
  --cinnabar:     #9A2D2D;  /* 朱砂 —— 主强调 / 印章 / 主 CTA */
  --cinnabar-soft:#B5463F;  /* 朱砂浅（hover） */
  --gold:         #C8A45C;  /* 金 —— 分隔 / 点缀 / 君药 */
  --gold-soft:    #D8BC84;
  --dai-qing:     #34505C;  /* 黛青 —— 次强调 / 链接 */
  --border-paper: rgba(31, 27, 22, 0.12);

  /* —— 藏青数据面 —— */
  --navy:         #1F3A5F;  /* 深色底 */
  --navy-2:       #16293F;  /* 更深（画布 / 凹陷） */
  --navy-card:    #24405F;  /* 深色卡片 */
  --on-navy:      #EAF0F6;  /* 深色上的主文字 */
  --on-navy-2:    #9FB2C8;  /* 深色上的次文字 */
  --jade:         #5FB3A1;  /* 玉色 —— 置信 / 成功 */
  --hl-path:      #F59E0B;  /* 橙 —— 图谱高亮路径 */

  /* —— 几何与阴影 —— */
  --radius:       12px;
  --radius-sm:    8px;
  --shadow:       0 4px 16px rgba(31, 27, 22, 0.10);
  --shadow-navy:  0 8px 28px rgba(11, 22, 38, 0.35);
}
```

### 对比度校验（WCAG）
- 墨 `#1F1B16` on 宣纸 `#F3ECDD` ≈ 13:1（AAA）
- 次文字 `#5C5345` on 宣纸 ≈ 5.3:1（AA）
- 深色字 `#EAF0F6` on 藏青 `#1F3A5F` ≈ 11:1（AAA）
- 朱砂 `#9A2D2D` on 宣纸 ≈ 5.6:1（AA，可作正文强调）

## 三、字体与排版

| 用途 | 字体 | 字号 / 字重 |
|---|---|---|
| 标题 | 思源宋体 / Noto Serif SC | H1 32 · H2 24 · H3 20 / 700 |
| 正文 | 思源黑体 / Noto Sans SC | **base 16px**（适老下限）· small 14 / 400–500 |
| 古籍原文摘录 | 宋体 | 16，朱砂或墨色，配引号 |
| 数字（统计 / 剂量 / 置信度） | tabular-nums 等宽 | — |

- 行高：正文 1.6–1.75；中文每行约 30–45 字换行。
- `font-display: swap`，宋体仅按需加载标题字重。

## 四、组件处理规范

### 通用
- **圆角**：卡片 12px，按钮 8px。
- **印章序号**：步骤 / 编号用朱砂方形印章圆标（圆角小、朱砂底白字、可带细描边）。
- **水墨分隔**：章节分隔用渐隐水墨横线（金或墨），非纯直线。
- **每屏一个主 CTA**：主操作用朱砂实心，次操作描边 / 文字按钮。

### 各模块要点
- **仿真辨证**：左对话=宣纸气泡；右结果区=藏青深色面板。八步卡片用朱砂印章序号，逐步淡入（每步 ~300ms，stagger）；证型雷达（主证金 30% 填充、候选黛青/玉）、君臣佐使图（君=金最大居中、臣=黛青、佐使=玉/灰）置于深色面发光；溯源标签点开→宣纸原文卡。
- **四时养生轮盘**：宣纸面，四季随节气配色（春青 / 夏朱 / 秋金 / 冬黛），水墨笔触分隔。
- **五脏调养**：宣纸面，五脏 SVG 人体图，选中朱砂高亮，侧抽屉滑出详情。
- **慢病助手**：宣纸面，**超大按钮 + 大字号**（适老核心），朱砂主 CTA，症状勾选降低输入门槛。
- **知识图谱**：藏青深色画布（节点 病证=朱砂 / 治法=黛青 / 方=金 / 药=玉，高亮路径=橙 `#F59E0B`），右侧宣纸结果列表做无障碍兜底。

### 图表（ECharts，沿用技能约束）
- **知识图谱**：≤100 节点用 SVG renderer，101–500 用 Canvas，>500 须先聚类；边 `#90A4AE` 60% 透明，高亮路径 `#F59E0B`；**必须配列表替代**。
- **证型雷达**：轴 5–8 个、最多 2–3 组数据；主证金色 30% 填充，描边满透明度。
- 所有图表提供 tooltip、图例可见、关键值直接标注；尊重 `prefers-reduced-motion`。

## 五、图标规范（硬性）

- **严禁使用 emoji 作为任何结构 / 功能 / 装饰图标**（跨平台不一致、无法主题化、不专业）。
- 统一使用**细线条国风 SVG 图标**，集中在 `components/GfIcon.vue`，通过 `name` 调用。
- 描边宽度统一（1.5px），`currentColor` 取色以适配深 / 浅表面；同层级图标尺寸一致（24px 基准）。
- 覆盖：五大模块（辨证 / 四时 / 五脏 / 慢病 / 图谱）、架构层（文献 / 向量 / 引擎 / 输出）、导航与通用动作。

---

## 六、无障碍与适老底线

- 正文 ≥16px；触控 / 点击目标 ≥44×44px。
- 颜色不作为唯一信息载体（配图标 / 文字）。
- 焦点态可见（朱砂或黛青 3px 描边）。
- 动效 150–300ms、仅 transform/opacity；尊重 `prefers-reduced-motion`。
- 每条 AI 输出页面附免责声明（医疗合规红线）。
