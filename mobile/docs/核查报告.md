## 仿真辨证（含语音 / 拍照） — 2026-06-10

### Round 1 · 程序角度
- `vue-tsc` 类型检查通过；`build:mp-weixin` 打包通过。
- **发现问题**：
  - P1：`dx-intake` 语音若 `recorder.start()` 因权限被拒失败，`onStop` 不回调 → `processing` 永久 `true`，转写浮层卡死。
  - P2：`transcribeAudio` 未校验 `statusCode`，后端 404（如未重启加载 /asr）时 404 JSON 被误解析。
- **修复**：P1 加 12s 看门狗（`onStop` 回调即撤销）；P2 加 `statusCode !== 200` reject。

### Round 2 · 测试角度（代码逻辑 + 模拟接口）
- 临时起 8011 后端实例验证新 `/api/asr/transcribe`：无 key 返回 `{text:"",configured:false,message:"…请手动输入"}` ✓。
- 客户端分支：`configured&&text`→填入；否则→toast 兜底手输；网络异常→catch toast ✓。
- 拍照：`chooseMedia`→preview→confirm→`tongueImg`→提交追加「（已拍摄舌象照片供参考）」标记 ✓。

### Round 3 · 用户角度（模拟输入 + 真接口 + 回调顺序）
- 语音回调链：`onVoiceStart`(start/vibrate/timer) → `onVoiceEnd`(pending=transcribe/processing=true/watchdog/stop) → `onStop` → `runTranscribe`(clearWatchdog/uploadFile) → resolve → `appendChief`。顺序正确，无卡死。
- 取消链：上滑→`cancelArmed`→release→pending=discard→`onStop` 早返回，不上传 ✓。
- inquiry 路由在新增 /asr 后仍正常（8011 实测 ready/type/session 正确）。

### 结论：**通过**（2 问题已修复并复核，build 绿）。
