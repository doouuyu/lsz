# 仿真辨证 · 多模态输入设计（语音 + 舌象拍照）

> 经 ui-ux-pro-max 设计引擎评估（2026-06-09）。沿用全局双表面设计系统（见 `docs/UI设计规范.md`）。
> 平台 uni-app vue3 微信小程序；单位 rpx；组件库 wot-design-uni。
> 最高准则：交互体验第一（见记忆 lsz-mobile-interaction-first）。

> **变更（2026-06-10）**：语音方案由「科大讯飞后端 ASR」改为「**微信同声传译插件 WechatSI**」端侧识别，**无需后端**。
> 插件：`provider=wx5050c5867e49331c`，manifest `mp-weixin.plugins.WechatSI`；`requirePlugin('WechatSI').getRecordRecognitionManager()`。
> `manager.start({lang:'zh_CN',duration:60000})` → `onRecognize`(实时文本) / `onStop`(最终 result) / `onError`；`manager.stop()`。
> ⚠️ 需用**已在微信公众平台「插件管理」添加同声传译**的正式 appid 才生效；临时/空 appid 下 `requirePlugin` 取不到 → 优雅降级「请手动输入」。

## 一、语音输入（按住说话 · 微信同声传译）

### 落点
录入卡 `dx-intake` 底部「按住说」按钮；问诊步进卡 `dx-question-card` 的补充 textarea 旁（后续）。
**可见替代**：文本输入框始终可用——语音是增强而非唯一通道（无障碍 `gesture-alternative`）。

### 交互状态机
| 状态 | 触发 | 视觉 | 反馈 |
|---|---|---|---|
| idle | — | 宣纸按钮「话筒 按住说」 | — |
| recording | touchstart | 全屏半透明蒙层 + 藏青录音卡（玉色波纹 + 计时 + 「上滑取消·松开发送」）；按钮变朱砂 | `vibrateShort` light |
| cancel-armed | touchmove 上滑 > 80px | 录音卡转朱砂 +「松开手指·取消」 | 颜色突变 |
| processing | touchend（有效）→ 上传转写 | 录音卡转「转写中…」+ 玉色脉冲点（非冻结，`loading-states`） | — |
| success | ASR 返回文本 | 蒙层淡出；文本追加进主诉输入框；轻提示 | `vibrateShort` |
| error/未配置 | 网络失败 / 后端无 key | toast「转写失败，请手动输入」+ 保留已录时长 | 恢复路径：可重录/手输（`error-recovery`） |

### 录音→转写链路
1. `uni.getRecorderManager()` start（format mp3/pcm，≤60s）。
2. `onStop` 拿 `tempFilePath`。取消或 <1s 丢弃。
3. `uni.uploadFile` 上传到后端 `POST /api/asr/transcribe`（multipart `audio`）。
4. 后端讯飞 IAT（env 占位 key，无 key 优雅返回 `configured:false`）。
5. 成功 → 追加文本；失败/未配置 → toast + 手输兜底。

### 动画
- 录音卡从按钮位 `scale+fade` 升起（`modal-motion`，源自触发点）。
- 波纹 5 条柱 `recPulse` 0.8s 错相；processing 时改玉色呼吸点。
- 退出 0.2s（`exit-faster-than-enter`）。`prefers-reduced-motion` 降级为静态。

### 无障碍（适老）
- 按钮 ≥88rpx；录音卡文字 ≥28rpx；取消区颜色 + 文字双指示（非仅色）。
- 蒙层 scrim rgba(31,27,22,0.45) 隔离前景。
- AI 免责：辨证页底部既有声明覆盖。

## 二、舌象拍照（`dx-tongue`）

### 落点
录入卡「拍舌象」入口 → 半屏/全屏拍照流程；结果缩略图进脉案、随主诉一并提交辨证上下文。

### 流程与 DOM
```
入口(宣纸按钮) → chooseMedia 动作面板[拍照 | 相册]
  → 取景预览层(navy 沉浸):
      <image 预览> + 椭圆取景框引导(虚线金框 + "请将舌体置于框内，自然伸舌")
      底部: [重拍(描边)]  [使用此张(朱砂主CTA)]
  → 确认 → 缩略图卡(宣纸): 80×80 缩略图 + "舌象已采集" + 删除(×)
```

### 交互/状态
| 状态 | 视觉 | 备注 |
|---|---|---|
| idle | 「拍舌象」入口（线描相机图标） | 可见控件 |
| choosing | `uni.chooseMedia` 系统面板 | sourceType=[camera,album] |
| preview | 取景层 + 金色椭圆引导 + 提示 | 重拍/确认双按钮，均 ≥88rpx |
| attached | 宣纸缩略图卡 + 删除 | 进脉案；可重拍替换 |
| uploading | 缩略图角标转圈（占位） | 上传 `/api/upload` 占位；失败保留本地路径 |

### 动画
- 取景层 `slide-up + fade` 进入；金色引导椭圆 `breathe` 2s 缓慢呼吸（描边 opacity 0.5↔0.9）。
- 缩略图卡 `stagger` 淡入。reduced-motion 降级。

### 与辨证链路
- 本轮拍照为**占位采集**：缩略图存本地 `tempFilePath`，文本侧在主诉后追加「（附舌象照片）」标记，使后端 inquiry/diagnose 知晓已采集舌象。真实舌诊图像分析后续接入。

## 三、技术要点
- 录音/相机权限：首次触发系统授权；拒绝 → toast 引导去设置。
- 后端 ASR：env `XF_APPID/XF_API_KEY/XF_API_SECRET`，缺省 `configured:false`，前端兜底手输。
- 单位 rpx；颜色取全局 token；图标走 `gf-icon`（禁 emoji）。
