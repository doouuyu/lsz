# 五脏调养 · 移动端设计

> ui-ux-pro-max 指导 + 双表面（宣纸面）。接 `GET /regimen/organ?organ=心|heart`。
> 数据：`data:{ title, color, element, function(脏腑功能), quote, quote_source, diet:[{name,desc,source}], herbal:[{name,desc,source}], herbs:[string], solar_term:{content,source}, source }`，顶层 `disclaimer`。

## 布局（单列）
1. `gf-navbar` 五脏调养（back）。
2. **五脏选择条**：心/肝/脾/肺/肾，选中染五行正色（心火 #C0504D、肝木 #5B8C5A、脾土 #C8A45C、肺金 #34505C、肾水 #1F3A5F）。
3. **Hero 卡**（左脉=脏色）：脏大字 + 五行 chip + `function` 脏腑功能 + 经典引文块（`quote` + `quote_source`，朱砂竖纹）。
4. **食疗 食养卡组**（seal 食）：`diet[]` 每条 name + desc + source。
5. **药膳卡组**（seal 膳）：`herbal[]` name + desc + source。
6. **常用药材**（seal 药）：`herbs[]` 药丸 tag 平铺。
7. **节气养生**（seal 节）：`solar_term.content` + source。
8. 免责声明。

## 交互/动画
- 切脏：loading→stagger 淡入各 section。脏色仅作强调脉/选中底，正文恒墨色。
- 失败 toast+重试；空字段隐藏对应 section。reduced-motion 降级。

## 复用
`gf-navbar/gf-icon/gf-seal/gf-card/gf-divider`；与四时养生同构，section 改为 功能/经典/食疗/药膳/药材/节气。
