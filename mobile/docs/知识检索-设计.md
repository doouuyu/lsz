# 知识检索 · 移动端设计

> ui-ux-pro-max 指导 + 双表面（宣纸面）。接 `GET /knowledge/search`（分页）、`GET /knowledge/stats`。
> 图谱（力导向）在小程序成本高/小屏体验差 → **移动端以「检索 + 分类浏览 + 条目详情」替代**，关联病证/证型/治法以标签呈现（无障碍兜底）。

## 数据
- stats：`{ total, verified, by_category:{理,法,方,药,养生}, engine }`
- search：`{ total, page, page_size, pages, items:[KnowledgeEntry] }`（empty q 浏览全部 2234；category 单独过滤；q+category 精检）
- KnowledgeEntry：`{ id, category, title, source{book,volume,section}, original_text, plain_explanation, related_diseases[], related_syndromes[], treatment_method, formula?, tags[], verified }`

## 布局
1. `gf-navbar` 知识检索。
2. **检索框**：input + 检索按钮（朱砂）；输入 300ms 防抖触发。
3. **分类筛选**：全部/理/法/方/药/养生 药丸（带 stats 计数）。
4. **统计行**：共 N 条 · 已核验 M。
5. **结果列表**：卡片（标题 + 分类 tag + 已核验徽 + 白话/原文摘要）；点 → 详情 sheet。
6. **分页**：scroll `@scrolltolower` 加载更多（追加），到底显示「已全部加载」。
7. 空态「未找到，换个关键词」；loading 骨架。

## 详情 sheet（宣纸 bottom sheet）
标题 + 分类/核验 + 出处 + 原文（朱砂宋体）+ 白话 + 关联病证/证型 tag + 治法。

## 交互/动画
- 防抖检索；切分类即时重检（page1）；加载更多追加（loadingMore 转圈）。
- 卡片 stagger 淡入；sheet 底部滑出。失败 toast+重试。reduced-motion 降级。

## 复用
`gf-navbar/gf-icon/gf-card/gf-divider`、`wd-popup`。
