# 四时养生 · 移动端设计

> ui-ux-pro-max 指导 + 全局双表面系统（宣纸面为主）。接 `GET /regimen/seasonal?season=春|spring`。
> 适老优先：大字、不藏 tab、高对比、触控 ≥88rpx。

## 数据
`data:{ title, color, element(木火土金水), organ, principle(内经原文), principle_source, quote(李时珍), advices:{ 起居|膳食|情志|功法:{content,source} }, source }`；顶层 `disclaimer`。

## 布局（单列竖排）
1. `gf-navbar` 四时养生（宣纸，back）。
2. **季节选择条**：四季药丸 春/夏/秋/冬，选中染该季色（春青/夏朱/秋金/冬黛，取 `data.color` 兜底）。进入按当前月份自动定位当令季。
3. **节气 Hero 卡**（宣纸，左侧 4rpx 季节色脉）：季节大字 + 五行/对应脏 chips + 内经 principle 引文块（朱砂竖纹引号 + principle_source）+ 李时珍 quote 印章块。
4. **四调卡 ×4**：起居/膳食/情志/功法，各 `gf-seal`（起/膳/情/功）+ content + `book` 出处脚注。**全部平铺不折叠**（适老，免点击）。
5. 免责声明脚注。

## 交互 / 动画
- 季节切换：请求中骨架/loading；返回后 Hero + 四调卡 **stagger 淡入**（每卡 +60ms，仅 transform/opacity）。
- 季节色作为 Hero 强调色脉与选中药丸底；正文恒墨色保证对比（色不单独承载信息，配字）。
- 失败：toast + 重试；空数据兜底「暂无内容」。
- `prefers-reduced-motion` 降级为直出。

## DOM 草图
```
view.seasonal
  gf-navbar
  scroll-view
    view.season-tabs > view.season-pill ×4
    view.hero.gf-card (style 左脉=季色)
      title + chips(element/organ)
      view.principle (引文 + source)
      view.quote (李时珍 印章块)
    view.advice.gf-card ×4 (seal + content + source)
    view.disclaimer
```
## 复用
`gf-navbar`/`gf-icon`/`gf-seal`/`gf-card`/`gf-divider`；季节色 token：春 #5B8C5A、夏 #C0504D、秋 #C8A45C、冬 #34505C。
