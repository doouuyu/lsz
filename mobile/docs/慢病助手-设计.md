# 慢病助手 · 移动端设计（适老核心）

> ui-ux-pro-max 指导：适老 = 大字（正文 ≥34rpx）、超大触控（CTA ≥104rpx）、高对比、低认知负荷、症状勾选降低输入门槛。
> 接 `GET /chronic/diseases`、`POST /chronic/quick-diagnose`。

## 数据
- diseases：`{ 病名:{ tcm_name, common_symptoms:[] } }`
- quick-diagnose 返回：`{ disease, syndrome, treatment, plan:{ 食疗,起居,功法,用药提示,随访提醒 }, sources:[KnowledgeEntry], disclaimer }`

## 两阶段
**pick（选择）**
1. `gf-navbar` 慢病助手。
2. 病种选择：6 病大药丸（高血压/糖尿病/冠心病/失眠/便秘/痹证），选中朱砂底。展示中医名（tcm_name）副标。
3. 症状勾选：选中病种的 `common_symptoms` 超大勾选行（整行可点，✓ 朱砂，≥96rpx）。
4. 底部固定 **一键辨证** 朱砂超大 CTA（未选症状禁用 + 提示）。

**result（结果）**
1. 证型 + 治法 banner（朱砂印章 + 大字）。
2. 调护方案 5 卡：食疗/起居/功法/用药提示/随访提醒（seal 食/居/功/药/访）。
3. 经典依据 sources：可点卡 → 原文/白话 bottom sheet。
4. 免责声明 + 「重新选择」。

## 交互/动画
- 勾选即时反馈（整行 press 高亮 + ✓）；一键辨证 loading（请求中禁用+转圈）。
- result 各卡 stagger 淡入；溯源 sheet 从底部滑出。
- 失败 toast+保留选择可重试；空症状禁止提交。reduced-motion 降级。

## 复用
`gf-navbar/gf-icon/gf-seal/gf-card`、`wd-popup`（溯源 sheet）。适老：本页字号整体上调。
